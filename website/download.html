YOUR FIRST FIVE MINUTES

From download
to Day 1.

  1. 01

    Bring a plan.

    Open New. Upload a supported file or paste text. JSON is the most reliable choice for a complex AI-generated roadmap.

  2. 02

    Review what came through.

    Check the weeks, dated days and real actions. Fix anything ambiguous before saving. A scanned PDF needs OCR first.

  3. 03

    Start your first day.

    Open the plan and choose Start Day 1. Check off work as you finish, add notes, and come back to your next step.

  4. 04

    Make a backup.

    Use Back up in your library. Desktop 1.7+ also saves recovery copies in Documents → Traqu Backups. Keep that folder when removing the app. On Android, choose Documents in the system save picker.

LOCAL MCP · DESKTOP

A connection to your workspace.

MCP is available in desktop 1.6.1+; the dedicated AI connections tab and workflow installers require 1.8.0+. Install your chosen AI app separately, then:

  1. Open Profile → AI connections (older versions: Profile → Preferences → AI connections).
  2. Choose Codex, Claude Desktop, Claude Code, Gemini CLI, Antigravity or Cursor.
  3. Keep read-only access, or explicitly allow edits.
  4. Click Connect, confirm, then restart your AI app.
  5. Ask: “Use Traqu to show my roadmaps and Day 1 tasks.”

Profile › AI connections

No Python, Node.js or terminal needed with the bundled app. Your agent’s own account requirements and tool approvals still apply.

Check the release version before downloading. If 1.6.1 is not published yet, use the source setup below or wait for the new installers.

Another client, a custom config, or Claude Desktop on Linux?

Use Copy configuration and merge its traqu entry into your client’s MCP settings. Claude Desktop on Linux may use a different settings location. Codex uses TOML: use its automatic setup or the documented CLI command instead of pasting JSON into its settings.

Want the Traqu plugin or agent skill?

In 1.8.0+, use the second card in AI connections. Codex and Claude Code can install a plugin through their installed CLI. Cursor, Gemini CLI and Antigravity can install a local skill. Keep MCP setup separate; the workflow does not grant editing access. Use Copy install steps if automatic installation is unavailable.

What can my agent actually do?

Read roadmaps, dated sections, tasks, notes, real activity and day history; preview a new plan. With editing enabled: create a roadmap, add tasks, append notes, rename tasks and mark work complete or reopen it. No deletion or arbitrary SQL tools are exposed.

A FEW HONEST DETAILS

Local means local.

How do updates keep my progress?

Desktop 1.7+ offers Check for updates in Library and Profile → Preferences. It saves a recovery backup before opening a newer official installer. Install over the app and keep its data and backup folders. Older versions need a manual export first. Android users should save a backup, then install a compatible APK over the existing app when possible.

Will my desktop and phone sync?

No automatic cloud sync is included. Each installation has its own workspace. Use export and import when moving plans, and keep backups before replacing an app.

Can a free ChatGPT browser chat use the local MCP server?

A browser chat cannot start the local stdio process. Remote or tunneled integrations are separate, account-dependent features. Traqu’s copy/import workflow works without that connection. Gemini browser Connected Apps also need a separate remote integration.

Does local MCP mean the AI model runs on my computer?

No. Traqu’s server and SQLite workspace are local, but information returned to your AI client may be sent to its model provider. Choose access carefully and follow that client’s data settings.

Where are the ZIP builds and checksums?

Each desktop release includes Mac ZIP alternatives and a SHA256SUMS.txt file. Open releases →. Download assets directly; no GitHub account is needed.
